# The removed GET /admin/dlq endpoint is not served

| | |

`GET /admin/dlq` returned an unbounded list. The accepted change removes it in favour of search on `state eq 'dead_lettered'` ([1.02](1.02-positive-list-dead-lettered-by-search.md)). A client still calling it must get a clear refusal, not an empty list.

## Setup
- At least one dead-lettered task exists, as in [1.01](1.01-positive-dead-lettered-task-parked-in-dlq.md).

## Request
```http
GET /api/task_engine/v1/admin/dlq HTTP/1.1
Host: api.example.com
Authorization: Bearer <admin-token>
```

## Expected response
- `404 Not Found` (no such route); no task data in the body.

## Side effects
<!-- No side effects: the route does not exist. -->

## Notes
- A `405` would also show removal if another method were still served on the path; none is.
