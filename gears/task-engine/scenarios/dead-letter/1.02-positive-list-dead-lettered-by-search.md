With `GET /admin/dlq` gone ([1.05](1.05-guardrail-admin-dlq-endpoint-removed.md)), operators list parked failures with the ordinary search: `$filter=state eq 'dead_lettered'`. A state filter with no queue or type filter fans out to every task domain (DESIGN.md:2835), so the listing covers all domains (PRD.md:815). A search whose state filter restricts it to `dead_lettered` is exempt from the `created_at` window, whatever its other filters (`queue`, `dead_lettered_from`, `type`): the set is bounded by retention, so no parked failure is missed however old it is (G-RTY-10). Listing needs only `read`; the caller sees its own scope, and re-enqueue still needs `admin`.

## Setup
- `{task_1}` (tenant A, from **reports**) created `T0`, dead-lettered at `T0+230s`; `{task_2}` (tenant A1, from **reports**) created `T0-2m`, dead-lettered at `T0+100s`. With task domains (p3), `{task_2}` lives in a second domain.
- `{task_3}` (tenant A, from **reports**), created 10 days before `T0`, dead-lettered 9 days before `T0`.
- Clock at `T0+300s`.

## Request
```http
GET /api/task_engine/v1/tasks?$filter=state%20eq%20'dead_lettered'&view=short HTTP/1.1
Host: api.example.com
Authorization: Bearer <admin-token>
```

## Expected response
- `200 OK`, a `JsonPage` with `{task_1}`, `{task_2}`, `{task_3}` (default order `created_at desc`, `id` tiebreak), each with `queue` = **dead_letter** and `dead_lettered_from` = **reports**.
- `{task_3}` **is** returned although it was created outside the default 7-day window.

## Notes
- The exemption covers any search whose state filter restricts it to `dead_lettered`, whatever its `queue`, `dead_lettered_from` or `type` filters (G-RTY-10, CONVENTIONS §5.9), so rows `state-and-dlq-queue` and `by-source-queue` also return `{task_3}`.
- An exempt search is keyset-paged on the results-table DLQ indexes (G-RTY-10); its order beyond the default `created_at desc` is not asserted here, and `$orderby=terminal_at` on it is not covered.
- Search items use the task resource's names (`assignment`, G-SEC-04); `short` carries `dead_lettered_from` (G-RTY-11). With no `limit` the page size is 25 (G-SEC-25).
