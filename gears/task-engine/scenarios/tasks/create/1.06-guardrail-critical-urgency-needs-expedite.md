# `critical` urgency needs the `expedite` action: 403 without it, accepted with it

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-priority-dispatch` (PRD.md:396) · `cpt-cf-task-engine-fr-authz` (PRD.md:922) · DESIGN.md:721 · DESIGN.md:1202 · DESIGN.md:2535 · `task_created` schema `urgency` |
| Phase | p1 |
| Test level | Integration — expedite grant |
| Gaps | G-CRT-08, G-SEC-19, G-CRT-24, G-WIRE-15 |

`critical` is the only setting that ranks one tenant's work above another's, so it needs `expedite` (PRD.md:396). The caller may create the task, so a refusal is `403`, not `404`. With `expedite`, the task is created with `urgency: critical`, which the claim serves before `normal` work.

## Setup
- `{creator_a}` holds `create` on **render** but not `expedite` (fixture policy).

## Request
Representative case: no `expedite`.
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json
Idempotency-Key: 7d1f0c2e-render-crit

{
  "type": "gts.cf.core.tasks.task.v1~acme.reports._.render.v1~",
  "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1",
  "urgency": "critical",
  "input": { "report_id": "r-52", "format": "pdf" }
}
```

## Expected response
- `403 Forbidden`, `permission_denied`, `context.reason: EXPEDITE_REQUIRED` (G-CRT-08, G-SEC-19). The body names no PDP rule and carries no field violation (G-WIRE-15).
```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "Urgency critical requires the expedite action",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": { "resource_type": "gts.cf.core.tasks.task.v1~acme.reports._.render.v1~", "reason": "EXPEDITE_REQUIRED" }
}
```

## Notes
- `EXPEDITE_REQUIRED` tells this `403` apart from a plain `create` denial (`ACTION_DENIED`) (G-CRT-08). The `expedite` check runs after the `create` PDP check and before the `Idempotency-Key` and payload checks (G-CRT-24), so a caller without `create` gets `ACTION_DENIED`, never `EXPEDITE_REQUIRED`.
