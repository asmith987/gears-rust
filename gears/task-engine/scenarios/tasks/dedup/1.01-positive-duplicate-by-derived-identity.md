# A duplicate by derived identity returns 409 without any key

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-derived-dedup` (PRD.md:296-309) · PRD.md:1493 · DESIGN.md:719 · DESIGN.md:1079 · DESIGN.md:2558-2571 · ADR-0012:56 |
| Phase | p2 |
| Test level | E2E |
| Gaps | G-CRT-25, G-CRT-24 |

For a type with a `dedup` trait the engine computes the identity from the validated input, so no `Idempotency-Key` is needed (PRD.md:308). A second create with equal `key_fields` values answers `409` with the holder's ID. Fields outside `key_fields` are not compared; the first accepted request wins (PRD.md:309).

## Setup
- **export**: `dedup { key_fields: ["/period"], scope: subject, window: active_or_succeeded }`; no `default_queue` (tasks go to **default**).
- At `T0`, `{creator_a}` created `{task_1}` with input `{ "period": "2026-10" }`, `priority: 100`, no key, no tags. It is `queued`.

## Request
Same `period`, different `priority` and tags, no key.
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json

{
  "type": "gts.cf.core.tasks.task.v1~acme.billing._.export.v1~",
  "priority": 5,
  "input": { "period": "2026-10" },
  "tags": [{ "key": "run", "value": "manual" }]
}
```

## Expected response
- `409 Conflict`, `already_exists`, `context.resource_type` = the task base type, `context.resource_name` = `{task_1}` (G-CRT-25). No `428`.
```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.already_exists.v1~",
  "title": "Already Exists",
  "status": 409,
  "detail": "A task with the same identity already exists",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": { "resource_type": "gts.cf.core.tasks.task.v1~", "resource_name": "{task_1}" }
}
```

## Side effects
- No new task; task {task_1}.priority is still `100` and its tags unchanged.

## Notes
- The first create (no key) returned `201`: the key requirement of PRD.md:278 does not apply to `dedup` types.
- The dedup lookup comes after validation and before the depth check (G-CRT-24), so a duplicate is answered `409` even when the queue or tenant is full ([idempotency/1.06](../idempotency/1.06-guardrail-replay-not-refused-as-full.md)).
