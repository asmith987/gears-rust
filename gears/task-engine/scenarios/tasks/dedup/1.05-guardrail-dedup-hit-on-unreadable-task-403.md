# A dedup hit on a task the caller may not read is 403 with no ID

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-derived-dedup` (PRD.md:312) · DESIGN.md:719 · DESIGN.md:1229 · DESIGN.md:2378 (3) · DESIGN.md:2594-2595 |
| Phase | p2 |
| Test level | Integration — same-tenant unreadable |
| Gaps | G-CRT-08, G-SEC-19, G-WIRE-15 |

A duplicate reveals the holder's ID only if the caller may read it; otherwise `403` and no ID (PRD.md:312). This can only happen under `tenant` scope, where the registrant accepted that the caller learns an identical task exists (DESIGN.md:2378 (3)).

## Setup
- **metric_job** as in [identity scope](1.04-guardrail-identity-scope.md).
- PDP policy for this scenario: `{creator_a2}` may `create` **metric_job** but may `read` only tasks with `created_by = {creator_a2}`.
- At `T0`, `{creator_a}` created `{task_1}` with input `{ "graph_id": "g-1", "metric": "pagerank", "revision": 7 }`.

## Request
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a2-token>
Content-Type: application/json

{ "type": "gts.cf.core.tasks.task.v1~acme.graph._.metric_job.v1~", "input": { "graph_id": "g-1", "metric": "pagerank", "revision": 7 } }
```

## Expected response
- `403 Forbidden`, `permission_denied`, `context.reason: DUPLICATE_NOT_READABLE` (G-CRT-08, G-SEC-19); no `resource_name`, no field violation, and `{task_1}` appears nowhere in the body.
```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "An identical task exists that you may not read",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": { "resource_type": "gts.cf.core.tasks.task.v1~", "reason": "DUPLICATE_NOT_READABLE" }
}
```

<!-- No side effects: the transaction is rolled back; no task, key or head changes. -->

## Notes
- `DUPLICATE_NOT_READABLE` tells this `403` apart from a `create` denial (`ACTION_DENIED`) (G-CRT-08). A test asserts the reason, the absence of the ID and that no task was created.
