# A supersede type rejects `cancellable: false`

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-task-supersede` (PRD.md:334) · DESIGN.md:720 · DESIGN.md:1228 · DESIGN.md:2561 · ADR-0012:66 |
| Phase | p2 |
| Test level | E2E |
| Gaps | G-CRT-07, G-SEC-21 |

A task that cannot be cancelled could never be superseded gracefully, so a supersede-enabled type refuses `cancellable: false` outright (PRD.md:334).

## Setup
- **metric_job** as in [1.01](1.01-positive-higher-order-supersedes-by-old-task-state.md). No task exists for the group.

## Request
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json

{ "type": "gts.cf.core.tasks.task.v1~acme.graph._.metric_job.v1~", "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1", "cancellable": false, "input": { "graph_id": "g-2", "metric": "pagerank", "revision": 1 } }
```

## Expected response
- `400 Bad Request`, `invalid_argument`, field violation `NOT_ALLOWED` on `/cancellable`.
```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "Tasks of a supersede-enabled type must be cancellable",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": { "field_violations": [ { "field": "/cancellable", "description": "type declares supersede; cancellable=false is not allowed", "reason": "NOT_ALLOWED" } ] }
}
```

<!-- No side effects: the request is refused before any write. -->

## Notes
- `NOT_ALLOWED` is in the decided reason set (G-CRT-07); the field is a JSON Pointer (G-SEC-21).
- `cancellable` defaults to `true` (G-CRT-27), so a supersede-type create that omits it is accepted.
