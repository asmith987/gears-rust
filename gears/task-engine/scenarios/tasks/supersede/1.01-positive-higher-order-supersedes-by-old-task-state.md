# A higher order value supersedes the group's unfinished task; how depends on its state and the mode

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-task-supersede` (PRD.md:319-337) · PRD.md:1494 · DESIGN.md:552 · DESIGN.md:577 · DESIGN.md:1510 · DESIGN.md:2378 (5) · DESIGN.md:2597-2603 · DESIGN.md:2639-2657 · ADR-0012:57 |
| Phase | p2 |
| Test level | E2E |

A newer revision makes the old task useless. The engine creates the new task and, in the same transaction, cancels the group's unfinished task with result `superseded` and `superseded_by` = the new ID (PRD.md:328). An unleased task has no worker to ask, so even `graceful` mode cancels it at once (DESIGN.md:552, :2667). A leased task in `graceful` mode gets a cancel request instead; in `forced` mode (work that needs exclusivity, PRD.md:336) it is cancelled at once, its lease token is cleared, its slots are freed, and there is no overlap window. "If that task finished at the same moment, there is nothing to replace and creation goes ahead" (PRD.md:328); the same holds when it finished long ago, and then no `cancel` right is needed.

## Setup
- **metric_job**: `dedup { key_fields: ["/graph_id", "/metric"], scope: tenant, window: active }`, `supersede { order_field: "/revision", mode: graceful }`. In this folder its tasks name **reports** explicitly.
- Task type `gts.cf.core.tasks.task.v1~acme.graph._.metric_job_excl.v1~` (**metric_job_excl**): as **metric_job** but `supersede { order_field: "/revision", mode: forced }`.
- Representative: at `T0`, `{creator_a}` created `{task_1}` with input `{ "graph_id": "g-1", "metric": "pagerank", "revision": 7 }` in **reports**. It is `queued`; `te_supersede_heads` has `latest_order = 7`, `latest_task_id = {task_1}`. Clock at `T0+10s`.

## Request
Representative case: old task unleased (`queued`), `graceful` type.
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json

{
  "type": "gts.cf.core.tasks.task.v1~acme.graph._.metric_job.v1~",
  "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1",
  "input": { "graph_id": "g-1", "metric": "pagerank", "revision": 8 }
}
```

## Expected response
- `201 Created` with `{task_2}`, `state: queued`, `input.revision` 8 in every case.
```json
{ "id": "{task_2}", "state": "queued", "superseded_by": null, "input": { "graph_id": "g-1", "metric": "pagerank", "revision": 8 }, "…": "other fields as in CONVENTIONS §5.1" }
```

## Side effects
Representative case:
- task {task_1} state is `cancelled`; task {task_1} result_code is `superseded`; task {task_1}.superseded_by is `{task_2}`; task {task_1}.terminal_at is `T0+10s`.
- timer `queue_timeout` and timer `lifetime` for {task_1} are removed; timer `queue_timeout` for {task_2} is armed at `T0+10s+3600s`, timer `lifetime` at `T0+10s+86400s`.
- history of {task_1} gains `taskCancelled` with `result_code: "superseded"`, `superseded_by: "{task_2}"`, `actor: "{creator_a}"`.
- history of {task_1} gains no `taskCancelRequested` (immediate supersession, G-CRT-17).
- history of {task_2} gains `taskCreated` with `initial_state: "queued"`; no `taskQueued` (G-SEC-23).
- `te_supersede_heads(tenant_a, group)` has `latest_order = 8`, `latest_task_id = {task_2}`.
- The identity row for revision 7 is absent (window `active`); the row for revision 8 names {task_2}.
- Both changes commit together: no reader ever sees {task_2} without {task_1} cancelled, or the reverse.

## Notes
- Events (G-CRT-17): an immediate or forced supersession records only `taskCancelled { superseded_by }`; a graceful supersession of a leased task records `taskCancelRequested { mode: graceful, superseded_by }` now and `taskCancelled { superseded_by }` when it ends. The `task_cancel_requested` schema gains the optional `superseded_by`.
- If the old task's state or the group head changes between the plan and the insert, the create re-plans (at most 3 attempts): [1.08](1.08-guardrail-plan-rechecked-when-old-task-gets-leased.md), G-CRT-19.
- Children of the superseded task: [supersession cancels children](1.03-positive-supersession-cancels-children.md).
