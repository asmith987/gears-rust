# A cancel without the cancel action gets 403, and of an unreadable task the same 404 as a missing task

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-authz` (PRD.md:918, :922) · `cpt-cf-task-engine-fr-tenant-scoping` (PRD.md:932) · DESIGN.md:1072, :1199 |
| Phase | p1 |
| Test level | Both — E2E other-tenant 404; integration cancel-action 403 |
| Gaps | G-SEC-19, G-WIRE-15 |

Cancel needs the task `cancel` action (DESIGN.md:1072). A caller that may read the task but lacks `cancel` gets `403`; a caller that may not read it gets exactly the response for a task that does not exist, even if it holds `cancel` elsewhere (no existence oracle, PRD.md:918, DESIGN.md:1199).

## Setup
- `{task_1}`: **render** on **reports**, owned by `{tenant_a}`, `queued`. `{reader_a}` has task `read` only.

## Request
```http
POST /api/task_engine/v1/tasks/{task_1}/cancel HTTP/1.1
Host: api.example.com
Authorization: Bearer <readonly-a-token>
Content-Type: application/json

{ "mode": "requested" }
```

## Expected response
- `403 Forbidden`, `permission_denied`, `context.reason: ACTION_DENIED` (G-SEC-19); no field violations (G-WIRE-15).

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "not allowed to cancel this task",
  "instance": "/api/task_engine/v1/tasks/{task_1}/cancel",
  "trace_id": "<trace>",
  "context": { "resource_type": "gts.cf.core.tasks.task.v1~", "reason": "ACTION_DENIED" }
}
```

## Side effects
<!-- No side effects in either case: the request is refused before any write; no taskCancelRequested, and the task keeps its state. -->

## Cases

| Case | Differs from the representative request | Expected | Notes |
|---|---|---|---|
| read-not-cancel | (representative) `{reader_a}` | `403` `permission_denied` `ACTION_DENIED` | PRD.md:918, :922 |
| unreadable | `{task_1}` `running`; caller `{creator_b}` (`Authorization: Bearer <creator-b-token>`, holds `cancel` in tenant B); `{ "mode": "forced" }`; `{task_9}` does not exist | `404` `not_found`, identical in shape to the response for `{task_9}`; `{task_1}` keeps running | PRD.md:918, :932; DESIGN.md:1199 |
