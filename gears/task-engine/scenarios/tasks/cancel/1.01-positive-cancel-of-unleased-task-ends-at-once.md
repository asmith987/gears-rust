# A cancel of a task that holds no lease ends it at once

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-task-cancel` (PRD.md:344, :349, :352) · `cpt-cf-task-engine-fr-dependencies` (PRD.md:839) · `cpt-cf-task-engine-fr-wait-conditions` (PRD.md:546) · DESIGN.md:499, :502-504, :549-550, :561, :1072, :2942-2944, :2951-2956 · `task_cancel_requested.v1`, `task_cancelled.v1` schemas · PRD.md:1485 |
| Phase | p1 (blocked case p2) |
| Test level | E2E |
| Gaps | G-RTY-15, G-SEC-11 |

A task that holds no lease (`queued`, `scheduled`, `blocked`, `waiting`) has no worker to ask, so `requested` and `graceful` cancel it immediately with result `cancelled`, and no grace timer is armed (PRD.md:352, DESIGN.md:550). `forced` also ends it at once, with result `forcibly_cancelled` (DESIGN.md:549). Finalize removes the task's state-specific timers and live-only rows in the same transaction (DESIGN.md:2942).

## Setup
- `{task_1}`: **render** on **reports**, created by `{creator_a}` at `T0`, `queued`, never claimed. Timers `queue_timeout` (`T0+3600s`) and `lifetime` (`T0+86400s`) are armed.

## Request
At `T0+10s`:
```http
POST /api/task_engine/v1/tasks/{task_1}/cancel HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json

{ "mode": "requested", "reason": "report no longer needed" }
```

## Expected response
- `200 OK`, task resource: `state: cancelled`, `result.result_code: cancelled`, `terminal_at` set (CONVENTIONS §5.5).

```json
{ "id": "{task_1}", "state": "cancelled", "cancel_requested": false,
  "result": { "result_code": "cancelled", "output": null, "error": null, "warnings": [] },
  "terminal_at": "2026-11-03T10:00:10Z", "…": "other fields as in CONVENTIONS §5.1" }
```

## Side effects
- Every case: timer `lifetime` for the task is removed; no `cancel_grace` timer is armed; history gains only `taskCancelled` (`actor: {creator_a}`, the request's `mode`), published; no `taskCancelRequested`, because no leased task was flagged (G-RTY-15). Children and successors are reached through finalize step 8 (DESIGN.md:2951-2956): see [hierarchy](../../hierarchy/children/).
- Representative case: task `{task_1}` state is `cancelled`; result_code is `cancelled`; timer `queue_timeout` for `{task_1}` is removed; the task leaves tenant A's queued set on **reports** (exit, DESIGN.md:561); metric `te_tasks_cancelled_total{queue="…acme.reports._.render.v1"}` increases by 1.

## Notes
- After an immediate or forced cancel `cancel_requested` reads `false`: the task was never flagged (G-RTY-15).
- The `actor`/`mode` names follow G-SEC-11 (`actor` everywhere) and G-RTY-15.
