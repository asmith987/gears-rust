# A task created cancellable false rejects requested and graceful cancels, and only forced stops it

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-task-cancel` (PRD.md:354) · DESIGN.md:549-551, :738 |
| Phase | p1 |
| Test level | E2E |
| Gaps | G-RTY-14, G-RTY-15 |

`cancellable=false` protects a task from routine cancellation: `requested` and `graceful` **MUST** be rejected (PRD.md:354), whether or not the task is leased. `forced` overrides it, because it is the emergency stop (PRD.md:354, DESIGN.md:549).

## Setup
- `{task_1}`: **render** on **reports**, created with `"cancellable": false`, `queued`.

## Request
```http
POST /api/task_engine/v1/tasks/{task_1}/cancel HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json

{ "mode": "requested" }
```

## Expected response
- `400 Bad Request`, `failed_precondition`, violation `{ type: STATE, subject: NOT_CANCELLABLE }`, `resource_name` = the task (G-RTY-14).

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.failed_precondition.v1~",
  "title": "Failed Precondition",
  "status": 400,
  "detail": "task {task_1} is not cancellable; only mode forced is allowed",
  "instance": "/api/task_engine/v1/tasks/{task_1}/cancel",
  "trace_id": "<trace>",
  "context": { "resource_type": "gts.cf.core.tasks.task.v1~", "resource_name": "{task_1}",
    "violations": [ { "type": "STATE", "subject": "NOT_CANCELLABLE", "description": "the task was created with cancellable=false" } ] }
}
```

## Side effects
- Rejected cases: none; no `taskCancelRequested` is recorded and `cancel_requested` stays `false`.

## Cases

| Case | Differs from the representative request | Expected | Notes |
|---|---|---|---|
| requested | (representative) | `400` `failed_precondition`, `NOT_CANCELLABLE` | G-RTY-14 |
| graceful | `{ "mode": "graceful" }` | same `400` response | G-RTY-14 |
| forced | task `running` under `{lt_1}`; `Authorization: Bearer <admin-token>`, `{ "mode": "forced", "reason": "stuck job, incident 4411" }` | `200`, `state: cancelled`, `result.result_code: forcibly_cancelled`, `cancellable: false`; as in the forced case of [Cancel of a leased task](1.02-positive-cancel-of-leased-task-by-mode.md): lease `{lt_1}` is invalid, slots released, only `taskCancelled` (`forcibly_cancelled`, `mode: forced`), no `taskCancelRequested` (G-RTY-15) | PRD.md:354, DESIGN.md:549 |
