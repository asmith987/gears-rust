# Entries are listed by time and filtered by type, time range and creator

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-task-entries` (PRD.md:632: "listable and filterable by type, time range, and creator") · DESIGN.md:985, :1088, :1762 |
| Phase | p1 |
| Test level | E2E |
| Gaps | G-EXE-18, G-SEC-25 |

A reader lists a task's entries in creation order and narrows them with filters. The list is served by `ix_te_entries_task (task_id, created_at, id)`; type and creator filters are applied inside that range (DESIGN.md:1762).

## Setup
- `{task_1}` has four entries:
  - `{entry_1}` `entry_work` by `{worker_a}` at `T0+15s`
  - `{entry_2}` `entry_note` by `{creator_a}` at `T0+20s`
  - `{entry_3}` `entry_work` by `{worker_a}` at `T0+40s`
  - `{entry_4}` `entry_work` by `{worker_a}` at `T0+90s`
- `{reader_a}` holds task `read` only.

## Request
```http
GET /api/task_engine/v1/tasks/{task_1}/entries?$filter=type eq 'gts.cf.core.tasks.entry.v1~cf.core.tasks.entry_work.v1~' and creator eq '{worker_a}' and created_at ge 2026-11-03T10:00:10Z and created_at lt 2026-11-03T10:01:00Z&limit=50 HTTP/1.1
Host: api.example.com
Authorization: Bearer <readonly-a-token>
```

## Expected response
- `200 OK`, a `JsonPage` with `{entry_1}` and `{entry_3}` in `created_at` order.

```json
{
  "items": [
    { "id": "{entry_1}", "task_id": "{task_1}", "type": "gts.cf.core.tasks.entry.v1~cf.core.tasks.entry_work.v1~", "creator": "{worker_a}", "payload": { "action": "render_pages", "summary": "rendered 12 pages", "details": { "pages": 12 } }, "created_at": "2026-11-03T10:00:15Z" },
    { "id": "{entry_3}", "task_id": "{task_1}", "type": "gts.cf.core.tasks.entry.v1~cf.core.tasks.entry_work.v1~", "creator": "{worker_a}", "payload": { "action": "upload" }, "created_at": "2026-11-03T10:00:40Z" }
  ],
  "page_info": { "next_cursor": null, "prev_cursor": null, "limit": 50 }
}
```
