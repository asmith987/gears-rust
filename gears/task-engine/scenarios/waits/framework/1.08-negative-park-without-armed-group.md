# Park with no armed group is refused

`/wait-conditions/park` parks an armed group. A worker that calls it without having armed one gets a refusal; the task keeps running under its lease.

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-wait-conditions` (PRD.md:557) · DESIGN.md:822, :1096 |
| Phase | p1 |
| Test level | E2E |
| Gaps | G-WAI-13 |

## Setup
- `{task_1}` is `running` under `{lt_1}`; it has no wait group.

## Request

```http
POST /api/task_engine/v1/tasks/{task_1}/wait-conditions/park HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json

{ "lease_token": "{lt_1}" }
```

## Expected response
- `400 Bad Request`, category `failed_precondition`, `subject: NO_ARMED_WAIT`; the worker keeps its lease.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.failed_precondition.v1~",
  "title": "Failed Precondition",
  "status": 400,
  "detail": "Task {task_1} has no armed wait group",
  "instance": "/api/task_engine/v1/tasks/{task_1}/wait-conditions/park",
  "trace_id": "<trace>",
  "context": {
    "resource_type": "gts.cf.core.tasks.task.v1~", "resource_name": "{task_1}",
    "violations": [ { "type": "STATE", "subject": "NO_ARMED_WAIT", "description": "park needs an armed wait group" } ]
  }
}
```

## Side effects
<!-- No side effects: the request is refused before any write. -->
- `{task_1}` stays `running`; `{lt_1}` stays valid (a heartbeat with it returns `outcome: ok`).
