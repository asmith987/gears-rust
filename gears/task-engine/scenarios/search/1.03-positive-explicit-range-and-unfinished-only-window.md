# An explicit created_at range of up to 31 days, or an unfinished-only state filter, replaces the default window

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-search` (PRD.md:1143) · DESIGN.md:1161, :2148, :2822-2826 |
| Phase | p1 |
| Test level | E2E |
| Gaps | G-RTY-10 |

A caller that wants older finished tasks names a `created_at` range. Any range of at most `search_max_window_days` (31) is accepted, wherever it lies in the stored history. Live tasks sit in the small live table, so a `state` filter that allows only non-terminal states reads it without any window: old stuck work is always findable.

## Setup
- Now is `T0`. Tenant A: `{task_6}` completed, created `2026-09-24T10:00:00Z`; `{task_2}` completed, created `2026-11-01T10:00:00Z`.

## Request
```http
GET /api/task_engine/v1/tasks?$filter=created_at ge 2026-09-10T00:00:00Z and created_at lt 2026-10-10T00:00:00Z&view=tiny HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
```

## Expected response
- `200`; `items` is exactly `{task_6}` (30-day range, no default window added).

## Cases

| Case | Differs from the representative request | Expected | Notes |
|---|---|---|---|
| closed range within 31 days | (representative) | exactly `{task_6}` | |
| lower bound only | `$filter=created_at ge T0-20d` | accepted, taken as `[T0-20d, now]` (20 days); returns `{task_2}` | the docs do not say how an open range is measured (assumed up to `now`) |
| unfinished-only state filter | Tenant A: `{task_8}` **render** `waiting`, created `T0-60d`; `{task_1}` `queued`, created `T0-1h`. `$filter=state in ('scheduled', 'queued', 'blocked', 'claimed', 'running', 'waiting')` | `{task_1}`, `{task_8}`; no window applied | DESIGN.md:2824 |
| unfinished-only with a wide range | the unfinished-only filter plus a `created_at` range wider than 31 days | accepted | |
| `ne` a terminal state | `$filter=state ne 'completed'` | the default window applies (still allows `failed`, `cancelled`, `dead_lettered`) | whether the engine recognises `not (state in (…terminal))` as unfinished-only is not specified |

## Notes
- A range wider than 31 days without an unfinished-only filter is refused: [unsupported query](1.06-negative-unsupported-query.md).
- The only terminal-state search without a window is one whose state filter restricts it to `dead_lettered`, whatever its other filters (G-RTY-10): [DLQ listing](../dead-letter/1.02-positive-list-dead-lettered-by-search.md).
