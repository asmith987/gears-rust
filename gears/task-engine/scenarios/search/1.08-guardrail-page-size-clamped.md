# Page size is clamped to 100, and to 20 at view=full

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-search` (PRD.md:1144) · DESIGN.md:1161, :2150-2151, :2827 |
| Phase | p1 |
| Test level | E2E |
| Gaps | G-SEC-25 |

The extractor does not cap the page size (`limit`, alias `$top`), so the handler clamps it. A larger request is served, not refused, and `page_info.limit` says what was applied. Without `limit` the page size is 25.

## Setup
- Tenant A has 250 `queued` tasks in the default window.

## Request
```http
GET /api/task_engine/v1/tasks?limit=500&view=tiny HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
```

## Expected response
- `200`; 100 items, `page_info.limit = 100`, `next_cursor` set.
- With `view=full` the same request returns 20 items, `page_info.limit = 20`.
- The same request with `$top=500` instead of `limit` is identical (alias); with both `limit=500&$top=500` → `400` (one value, two spellings).
- Without `limit`: 25 items, `page_info.limit = 25`.
