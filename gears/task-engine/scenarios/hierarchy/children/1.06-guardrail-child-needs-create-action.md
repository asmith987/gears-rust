# Holding the parent's lease is not enough: the child also needs `create`

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-link-authz` (PRD.md:855) · `cpt-cf-task-engine-fr-authz` (PRD.md:925) · DESIGN.md:995, :2534 |
| Phase | p2 |
| Test level | Integration — create grant |
| Gaps | G-SEC-19 |

A worker identity normally has only `claim` and `read`. To create children of its own task it needs `create` for the child's type and queue, plus the parent's lease (PRD.md:925, DESIGN.md:995). The lease proves the link; it does not grant the right to create tasks.

## Setup
- `{task_1}` (**render**, tenant A) is `running` under `{worker_a}` with `{lt_1}`.
- PDP denies `create` on **render** in **reports** to `{worker_a}` for this scenario (its `claim` and `read` stay).

## Request
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json
Idempotency-Key: child-no-create-1

{
  "type": "gts.cf.core.tasks.task.v1~acme.reports._.render.v1~",
  "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1",
  "input": { "report_id": "r-42-part-3", "format": "pdf" },
  "parent_task_id": "{task_1}",
  "parent_lease_token": "{lt_1}"
}
```

## Expected response
- `403 Forbidden`, `permission_denied`. The `create` check runs first, before the transaction (DESIGN.md:2534), and concerns the new task, not the parent, so it reveals nothing about `{task_1}`.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.permission_denied.v1~",
  "title": "Permission Denied",
  "status": 403,
  "detail": "Not allowed to create tasks of this type in this queue",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": { "reason": "ACTION_DENIED" }
}
```

## Side effects
- Nothing is written. task `{task_1}` is still `running`; lease `{lt_1}` is still valid (a create is not a lease-fenced call, so no release on denial, DESIGN.md:1022).

## Notes
- A plain denial of the action is `ACTION_DENIED`, from the closed `403` reason list (G-SEC-19).
