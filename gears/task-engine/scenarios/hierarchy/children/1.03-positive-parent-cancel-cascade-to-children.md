# Cancelling a parent cancels its unfinished children, unless it opted out

With the default `propagate_cancel: true`, the parent's terminal `cancelled` transition starts the children cascade in the same transaction (finalize step 8, DESIGN.md:2955 runs it only when `t.propagate_cancel`). Each unfinished child is cancelled in the parent's mode (G-WAI-23): unleased children end at once, leased children get `cancel_requested` under `requested`/`graceful` (plus a `cancel_grace` timer for `graceful`), and a `forced` parent cancel ends every child `forcibly_cancelled`. Finished children are untouched. Children are cancelled through the shared cascade: the first `cascade_inline_limit` (100) in the parent's own transaction, the rest by a durable `cascade` timer in bounded batches; each step is a guarded update on the child's expected state, so a replay after a crash skips children already done. A force-cancelled parent does not wait for its children (PRD.md:828). A parent created with `propagate_cancel: false` opts out: its own cancellation ends only itself, even when `forced`.

This folder is the home of the cancel cascade to children; supersession's cascade lives in [tasks/supersede](../../tasks/supersede/).

## Setup
- `{task_1}` (**render**, tenant A, `propagate_cancel: true`) is `waiting` on a children condition `{wc_1}` (parked), so it holds no lease.
- Children: `{task_2}` `queued`, `{task_3}` `scheduled` (retry backoff), `{task_4}` `completed`.

## Request
```http
POST /api/task_engine/v1/tasks/{task_1}/cancel HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json

{ "mode": "requested", "reason": "report withdrawn" }
```

## Expected response
- `200 OK`, task resource: `state: cancelled`, `result.result_code: cancelled` (unleased task, so not `202`: there is no worker to ask; CONVENTIONS §5.5, PRD.md:352, DESIGN.md:550).

```json
{
  "id": "{task_1}",
  "state": "cancelled",
  "result": { "result_code": "cancelled", "output": null, "error": null, "warnings": [] },
  "terminal_at": "2026-11-03T10:00:00Z",
  "…": "other fields as in CONVENTIONS §5.1"
}
```

### Case `propagate_leased_child_requested` — side effects
- condition `{wc_1}` state is `cancelled`; its row stays until retention (G-WAI-14); timer `lifetime` for `{task_1}` is removed.
- history of `{task_1}` gains `taskCancelled` with `result_code = cancelled`; history of `{task_2}` and `{task_3}` each gain `taskCancelled` with `result_code = cancelled`.
- the `requested` mode reaches a leased child as a request: `{task_4}.cancel_requested` is true and it decides itself; history of `{task_4}` gains `taskCancelRequested` with `mode: requested` and no `actor`; no `cancel_grace` timer for `{task_4}`.
- when `{task_4}` later ends, `te_timers(children_check for {task_1})` stays absent: children that end afterwards do not try to wake the ended parent (DESIGN.md:2995).

### Case `opt_out_forced` — side effects
- No `cascade` timer for `{task_1}` exists.
- Later, when `{task_2}` and `{task_3}` end, no `children_check` timer is inserted for `{task_1}` (DESIGN.md:2956 inserts one only while the parent is live).
- The children keep `parent_task_id = {task_1}`; reading them still shows the link to the ended parent.

### Case `forced_large_fanout_crash` — side effects
- In the parent's transaction: children `{task_c001}`…`{task_c100}` state is `cancelled`, result_code `forcibly_cancelled`, and `te_timers(cascade for {task_1})` is present with `cascade_kind = children`, `cascade_after_task_id = {task_c100}` (DESIGN.md:2978-2979).
- Within one timer-wheel tick: batch 101-200 commits, the timer is re-armed with `cascade_after_task_id = {task_c200}`; after the crash the timer's claim expires and the new instance continues with 201-250, then deletes the timer (DESIGN.md:2982-2984).
- Every child ends `cancelled` with result_code `forcibly_cancelled` exactly once: history of each `{task_cNNN}` gains exactly one `taskCancelled` (`mode: forced`, no `actor`), also for children the crashed batch had touched.
- `{task_c010}` (leased) is ended at once (`forcibly_cancelled`, no `taskCancelRequested`), its lease is invalid, its concurrency slots are released.
- After the cascade: `te_timers(cascade for {task_1})` is absent; `GET /tasks?$filter=parent_task_id eq '{task_1}' and state ne 'cancelled'` returns no items (the `parent_task_id` search filter is accepted, Proposals › API reads and responses).

## Side effects (case `propagate_unleased`)
- task `{task_1}` state is `cancelled`; condition `{wc_1}` state is `cancelled` (the row stays until retention, G-WAI-14); timer `wait` for `{task_1}`, if any, is removed.
- task `{task_2}` state is `cancelled`, result_code `cancelled`; task `{task_3}` state is `cancelled`, result_code `cancelled` — in the same transaction as `{task_1}`.
- task `{task_4}` is unchanged (`completed`).
- timer `queue_timeout` for `{task_2}` and timer `scheduled` for `{task_3}` are removed.
- `{task_1}` (waiting) and `{task_3}` (scheduled) leave the deferred set; `{task_2}` leaves the queued set.
- history of `{task_2}` and of `{task_3}` gains `taskCancelled` with `result_code: cancelled` and no `actor` (engine cascade, schema `actor` description).
- event `taskCancelled` for `{task_1}`, `{task_2}`, `{task_3}` is published to the task-events topic.
- No `cascade` timer is created.

## Notes
- Mode and result code follow G-WAI-23 (the DESIGN cascade body, DESIGN.md:2955, :2972-2985, does not say them yet): the parent's mode reaches each unfinished child; children end `cancelled`, or `forcibly_cancelled` when forced, never `superseded` (G-CRT-21). PRD.md:828 "cancelled exactly once" is read as "ends in the cancelled family exactly once".
- `opt_out_forced`: even `forced` respects the opt-out: PRD.md:826 makes `propagate_cancel` the only switch, and PRD.md:828 (every child cancelled exactly once) applies to the propagating case.
- A parent with `propagate_cancel: true` that ends in another non-success state (failed, dead-lettered, timed out) cascades in `graceful` mode: [1.04](1.04-positive-parent-failure-cancels-children-gracefully.md) (G-WAI-38).
