# A `wait_for_children` parent cannot complete successfully while a child is unfinished

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-parent-child` (PRD.md:826) · DESIGN.md:736, :1233 |
| Phase | p2 |
| Test level | E2E |
| Gaps | G-WIRE-14, G-WAI-38, G-WAI-24 |

With `wait_for_children: true`, the parent's `success` or `warning` completion is rejected while any child is non-terminal. The worker keeps its lease and should park on a children condition instead (PRD.md:826, [waits/children](../../waits/children/)).

## Setup
- `{task_1}` (**render**, tenant A) was created with `wait_for_children: true`; it is `running` under `{worker_a}` with `{lt_1}`.
- Its worker created children `{task_2}` (`completed`) and `{task_3}` (`running` under `reports-7f9c-2`).

## Request
```http
POST /api/task_engine/v1/tasks/{task_1}/complete HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json

{ "lease_token": "{lt_1}", "result_code": "success", "output": {"url": "https://files.example.com/r-42.pdf"} }
```

## Expected response
- `400 Bad Request`, `failed_precondition`, violation `{ type: "STATE", subject: "CHILDREN_PENDING" }`, `resource_name` = the task (DESIGN.md:1233; no `context.reason`, G-WIRE-14).

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.failed_precondition.v1~",
  "title": "Failed Precondition",
  "status": 400,
  "detail": "Task has unfinished children",
  "instance": "/api/task_engine/v1/tasks/{task_1}/complete",
  "trace_id": "<trace>",
  "context": {
    "resource_type": "gts.cf.core.tasks.task.v1~",
    "resource_name": "{task_1}",
    "violations": [ { "type": "STATE", "subject": "CHILDREN_PENDING", "description": "at least one child task is not terminal" } ]
  }
}
```

## Side effects
- task `{task_1}` state is `running`; lease `{lt_1}` is still valid; `queue_global` and `queue_tenant` slots unchanged.
- task `{task_3}` is unchanged.
- No `taskCompleted` in the history of `{task_1}`.

## Notes
- The count of pending children is not disclosed.
- Only a *successful* completion is gated (PRD.md:826); `result_code: error` is accepted. If it ends the parent, a parent with `propagate_cancel: true` cancels its unfinished children gracefully (G-WAI-38, [1.04](1.04-positive-parent-failure-cancels-children-gracefully.md)); a retryable error with retries left schedules the parent and touches no child.
- A child re-enqueued while its parent is non-terminal makes the parent's success `CHILDREN_PENDING` again until that child ends (G-WAI-24).
