# Creates alone can never build a dependency cycle

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-dependencies` (PRD.md:841 — cycle rule) · DESIGN.md:2638, :2870 |
| Phase | p2 |
| Test level | E2E |
| Depends on | Proposals › Task mutability › Set only in the create request |
| Gaps | G-WAI-03, G-WAI-42 |

A new task has no successors, so whatever predecessors it names, it cannot close a cycle (DESIGN.md:2638, :2870). With the dependency endpoints removed ([1.05](1.05-guardrail-dependency-endpoints-removed.md)), every graph is built in creation order and is acyclic by construction; `CYCLE_DETECTED` can no longer occur, and creates take no per-tenant graph lock.

## Setup
- `{task_1}` (**render**, tenant A) is `queued`; `{task_2}` was created with predecessor `{task_1}` and is `blocked`.

## Request
Create `{task_3}` naming both, including the task that already depends on the other:
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json
Idempotency-Key: diamond-tail-1

{
  "type": "gts.cf.core.tasks.task.v1~acme.reports._.render.v1~",
  "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1",
  "input": { "report_id": "r-42-tail", "format": "pdf" },
  "predecessors": [ { "task_id": "{task_2}" }, { "task_id": "{task_1}" } ]
}
```

## Expected response
- `201 Created`, `{task_3}` `blocked` on `{task_1}` and `{task_2}`. No cycle check runs; the only graph bound is the predecessor count ([1.04](1.04-negative-predecessor-list-refusals.md)).

## Side effects
- `te_dependencies({task_3}, {task_1})` and `({task_3}, {task_2})` are present.
- No per-tenant graph lock is taken (`te_dependency_locks`, DESIGN.md:1599, is removed with the dependency additions, G-WAI-03).

## Notes
- A predecessor ID can only be an existing task, and a task's own ID is assigned by the engine, so self-links are impossible.
- The same `task_id` listed twice in one create is refused with `400 DUPLICATE` on the second occurrence (G-WAI-42; [1.04](1.04-negative-predecessor-list-refusals.md) case `duplicate`).
- With additions gone, `te_dependency_locks`, the DFS and `CYCLE_DETECTED` (DESIGN.md:2877-2898) are removed (G-WAI-03).
