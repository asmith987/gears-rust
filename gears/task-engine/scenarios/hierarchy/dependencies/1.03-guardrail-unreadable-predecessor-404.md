# A predecessor the caller cannot read, in another tenant or in another domain, gets 404, never 403

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-link-authz` (PRD.md:854, :856, :857) · DESIGN.md:727-728, :1200, :2634-2636 · PRD.md:1505 |
| Phase | p2 |
| Test level | Both — E2E other-tenant row; integration unreadable and other-domain rows (PDP double, two-domain deployment) |
| Gaps | G-WAI-41, G-WIRE-15 |

Naming a predecessor needs `read` on it (PRD.md:856). A missing, foreign or policy-hidden predecessor gets the same `404`, and so does one in another task domain: a create looks up linked tasks only in the new task's domain (G-WAI-41). The `404` carries no field violation (G-WIRE-15). State checks (unsatisfiable) run only after this, so the error never tells whether the task exists or how it ended.

## Setup
- `{task_1}` (**render**) belongs to tenant B and ended `failed`.
- `{task_2}` (**render**, tenant A) is `queued`.
- `{creator_a}` cannot read `{task_1}`.

## Request
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json
Idempotency-Key: foreign-pred-1

{
  "type": "gts.cf.core.tasks.task.v1~acme.reports._.render.v1~",
  "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1",
  "input": { "report_id": "r-42-merged", "format": "pdf" },
  "predecessors": [ { "task_id": "{task_2}" }, { "task_id": "{task_1}" } ]
}
```

## Expected response
- `404 Not Found`, `not_found`, only `resource_type` and `resource_name` in `context`, no field violation — the same body as for a random UUID; not the `400` unsatisfiable answer that the failed `{task_1}` would give a reader.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.not_found.v1~",
  "title": "Not Found",
  "status": 404,
  "detail": "Predecessor task not found",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": {
    "resource_type": "gts.cf.core.tasks.task.v1~",
    "resource_name": "{task_1}"
  }
}
```

## Notes
