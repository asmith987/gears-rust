# The dependency endpoints no longer exist

Dependencies are fixed at creation. Adding a predecessor later raced with claims and needed the per-tenant graph lock and a cycle search (DESIGN.md:2870-2906), and a blocked successor can no longer be unblocked by removing a link; both endpoints are removed. Any caller, even one with every task action, gets the "no such route" answer and nothing changes. The accepted replacement for removal is `on_predecessor_failure: ignore` plus cancelling the hung predecessor ([1.02](1.02-positive-predecessor-outcome-moves-successor.md) case `all_failed_ignore`); a `cancel` link past a hung predecessor means cancelling both and creating the successor again.

## Setup
- `{task_1}` and `{task_2}` (**render**, tenant A) are `queued`. `{admin}` holds every task action.

## Request
```http
POST /api/task_engine/v1/tasks/{task_2}/dependencies HTTP/1.1
Host: api.example.com
Authorization: Bearer <admin-token>
Content-Type: application/json

{ "predecessors": [ "{task_1}" ], "mode": "all" }
```

## Expected response
- `404 Not Found`, `not_found`: the routes are not registered, so the router answers `404` (G-WAI-03).

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.not_found.v1~",
  "title": "Not Found",
  "status": 404,
  "detail": "No such endpoint",
  "instance": "/api/task_engine/v1/tasks/{task_2}/dependencies",
  "trace_id": "<trace>"
}
```

## Cases

| Case | Setup differs | Request | Expected | Side effects |
|---|---|---|---|---|
| `add_dependency` | (the representative Setup) | `POST /tasks/{task_2}/dependencies` as above | `404` | task `{task_2}` is still `queued` (never moved to `blocked`); no `te_dependencies` row for `{task_2}` |
| `remove_dependency` | `{task_2}` is `blocked` on `{task_1}` (`running`, link `cancel`) | `DELETE /api/task_engine/v1/tasks/{task_2}/dependencies/{task_1}` with `<admin-token>`, no body | `404`, `instance: /api/task_engine/v1/tasks/{task_2}/dependencies/{task_1}` | task `{task_2}` is still `blocked`; `te_dependencies({task_2}, {task_1})` is still present |

## Side effects
- Nothing changes (per case above).
