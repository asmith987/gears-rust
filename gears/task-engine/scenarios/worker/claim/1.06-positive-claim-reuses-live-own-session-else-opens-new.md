# A claim reuses the caller's live `session_id`; an expired, unknown or foreign one opens a new session

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-heartbeat` (PRD.md:676) · DESIGN.md:1918, :1929, :2408, :2498 · ADR-0017:54-57, :80, :81 |
| Phase | p1 |
| Test level | Both — expired-session row |
| Gaps | G-CLM-17 |

One worker process has one session per domain; every lease it holds there belongs to it, and one heartbeat renews them all. A process that already has a session sends its `session_id` on later claims; the engine attaches the new task to the same session and renews it. A session cannot be revived: a claim that names an expired session, or an ID the engine does not know, is not refused; the engine opens a fresh session and returns its ID (ADR-0017:55), so a restarted process always gets a new session. `session_id` is not a credential either: every use also needs `worker_subject = caller` (DESIGN.md:1918), so a subject that learns or guesses another principal's session ID cannot attach tasks to it or renew it; its claim simply opens a session of its own, with the same answer as for an unknown ID. A `session_id` sent with a `worker_id` other than the one that opened it counts the same way (G-CLM-17).

## Setup (representative case: live own session)
- `reports-7f9c-1` of `{worker_a}` holds `{task_1}` in session `{session_1}` (`lease_secs: 30`, `active`, `lease_until: T0+30s`).
- **reports** holds one more `queued` task `{task_2}`. Clock `T0+20s`.

## Request
```http
POST /api/task_engine/v1/tasks/claim HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json

{ "worker_id": "reports-7f9c-1", "session_id": "{session_1}",
  "queues": ["gts.cf.core.tasks.queue.v1~acme.reports._.render.v1"], "max_tasks": 1, "timeout_secs": 0 }
```

## Expected response
- `200 OK`, `session_id` is `{session_1}` (the same ID), one claim for `{task_2}`.

```json
{ "session_id": "{session_1}", "heartbeat_interval_secs": 10,
  "claims": [ { "task": { "id": "{task_2}", "state": "claimed", "…": "other fields as in CONVENTIONS §5.1" },
                "lease": { "lease_token": "{lt_2}", "lease_epoch": 1, "attempt": 1, "lease_secs": 30 },
                "authority": { "…": "…" }, "resumed": null } ] }
```

## Notes
- A stored `worker_id` that differs from the claim's counts like an unknown or foreign session (G-CLM-17).
