# A claim naming an unregistered queue gets `404`

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-gts-queue` (PRD.md:987, :995 "claims MUST name registered queues") · DESIGN.md:1064, :2404-2433 |
| Phase | p1 |
| Test level | E2E |
| Gaps | G-CLM-15, G-CLM-18, G-CRT-03 |

A claim must name registered queues. An unknown queue ID is answered at once with `404 not_found`, the same answer as `GET /queues/{id}` ([queues/1.02](../../queues/1.02-negative-unknown-queue-not-found.md)): no session is opened, no long-poll wait, nothing is claimed from the other queues the request names. Queues are platform registrations, not tenant data, so naming the missing ID reveals nothing.

## Setup
- **reports** is registered; `gts.cf.core.tasks.queue.v1~acme.reports._.nosuch.v1` is not.
- `{worker_a}` has no session.

## Request
```http
POST /api/task_engine/v1/tasks/claim HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json

{ "worker_id": "reports-7f9c-1", "session_id": null,
  "queues": ["gts.cf.core.tasks.queue.v1~acme.reports._.render.v1", "gts.cf.core.tasks.queue.v1~acme.reports._.nosuch.v1"],
  "max_tasks": 1, "timeout_secs": 30 }
```

## Expected response
- `404 Not Found` at once (no wait), `not_found`, naming the first unknown queue.

```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.not_found.v1~",
  "title": "Not Found",
  "status": 404,
  "detail": "Queue gts.cf.core.tasks.queue.v1~acme.reports._.nosuch.v1 not found",
  "instance": "/api/task_engine/v1/tasks/claim",
  "trace_id": "<trace>",
  "context": { "resource_type": "gts.cf.core.tasks.queue.v1~", "resource_name": "gts.cf.core.tasks.queue.v1~acme.reports._.nosuch.v1" }
}
```

<!-- No side effects: the request is refused before any write; no session is opened. -->

## Notes
- Decided in the wire review (G-CLM-15). The registry check runs after field validation and before the PDP (G-CLM-18); an empty or missing `queues` array is `400 REQUIRED` on `/queues` ([1.07](1.07-negative-claim-request-validation.md)).
- `POST /tasks` naming an unknown queue is `404` too (G-CRT-03).
