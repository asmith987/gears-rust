# Each new lease carries a larger lease epoch

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-lease-fencing` (PRD.md:724) · `cpt-cf-task-engine-fr-execution-semantics` (PRD.md:740) · DESIGN.md:565-577 · ADR-0011:60, :66, :82 |
| Phase | p1 |
| Test level | E2E |

The lease epoch grows with every lease and never decreases, so a worker can pass it to an external store that rejects writes with an older epoch. It is kept across `claimed → running` and is not reset by a requeue, a release or a retry (DESIGN.md:565-577).

## Setup
- `{task_1}`: **render** task on **reports**, never claimed (`lease_epoch` 0).
- At `T0` `reports-7f9c-1` claims it: `lease.lease_epoch: 1`, `lease.attempt: 1`, token `{lt_1}`. It starts the task, then releases it at `T0+5s` ([Release a running task](../release/1.01-positive-release-returns-task-to-queue.md)).

## Request
At `T0+6s` `reports-7f9c-2` claims again:
```http
POST /api/task_engine/v1/tasks/claim HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json

{ "worker_id": "reports-7f9c-2", "session_id": null, "queues": ["gts.cf.core.tasks.queue.v1~acme.reports._.render.v1"], "max_tasks": 1, "timeout_secs": 30 }
```

## Expected response
- `200 OK`; the lease has a new token `{lt_2}` ≠ `{lt_1}` and `lease_epoch: 2`.
- `attempt` stays `1`: a release continues the same attempt (PRD.md:661).

```json
{
  "session_id": "{session_2}",
  "heartbeat_interval_secs": 10,
  "claims": [ {
    "task": { "id": "{task_1}", "state": "claimed", "attempt": 1, "…": "other fields as in CONVENTIONS §5.1" },
    "lease": { "lease_token": "{lt_2}", "lease_epoch": 2, "attempt": 1, "lease_secs": 30 },
    "authority": { "mode": "creator_verified", "checked": [], "checked_at": "2026-11-03T10:00:00Z" },
    "resumed": null
  } ] }
```

## Side effects
- task `{task_1}` lease_epoch is `2`; `GET /tasks/{task_1}` shows `assignment.lease_epoch: 2` and no `lease_token`.
- lease `{lt_1}` is invalid (later calls get LEASE_LOST).
- After a later session expiry and a third claim, `lease_epoch` is `3`; after `claimed → running` it is unchanged.
