# A full concurrency dimension holds back only the tasks it covers; the claim serves other tenants, queues and types

A full limit blocks only the tasks it covers: the claim moves on to other tenants, queues and types, so there is no head-of-line blocking (PRD.md:427). Per DESIGN.md:2511 a full `queue_tenant` dimension removes exactly one (queue, tenant) pair from the claim, a full `queue_global` removes that queue's whole stream and nothing else, and a full `type_global` blocks that type in every queue and only that type. A full scope costs reads only, no task-row write. Type limits follow the kind of work, not the queue: "at most 5 expensive AI inference tasks at once, wherever they are queued" (PRD.md:468); a task is assigned only when both its queue and its type dimensions have room.

## Setup (representative case: `queue_tenant`)
- **reports** (`per_tenant_concurrency_limit: 5`, `global_concurrency_limit: 50`):
  - `{tenant_a}`: 5 tasks `claimed` by `reports-7f9c-1`, and 10 more `queued`, created `T0` … `T0+9s`;
  - `{tenant_b}`: 3 tasks `queued`, `{task_b1}` … `{task_b3}`, created `T0+20s` … `T0+22s`.
- `{platform_worker}` may claim from **reports** for both tenants. Clock `T0+30s`.

## Request
```http
POST /api/task_engine/v1/tasks/claim HTTP/1.1
Host: api.example.com
Authorization: Bearer <platform-worker-token>
Content-Type: application/json

{ "worker_id": "platform-ops-1", "session_id": null,
  "queues": ["gts.cf.core.tasks.queue.v1~acme.reports._.render.v1"], "max_tasks": 3, "timeout_secs": 0 }
```

## Expected response
- `200 OK` with three claims: `{task_b1}`, `{task_b2}`, `{task_b3}`. No `{tenant_a}` task, although A's are older.

## Side effects
- tasks `{task_b1}` … `{task_b3}` state is `claimed`; A's 10 queued tasks stay `queued` and unchanged (no write to them).
- `queue_tenant(reports, {tenant_b}) used changes by +3`; `queue_tenant(reports, {tenant_a}) used` stays 5; `queue_global(reports) used changes by +3`.
- metric `te_claim_capacity_skipped_total{queue="…reports.render.v1", dimension="queue_tenant"}` increases by at least 1.

- `queue_tenant`, `queue_global` and `type_global` name concurrency counters only (DESIGN.md:1568, :1582); depth dimensions use the `429` names `queue`, `tenant`, `domain_global`, `deferred` (G-CLM-30).
