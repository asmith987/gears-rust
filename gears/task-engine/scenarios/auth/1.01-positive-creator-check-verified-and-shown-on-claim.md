# A passed creator check is recorded and handed to the worker on claim

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-worker-principals` (PRD.md:958) · DESIGN.md:1037, :1043 |
| Phase | p1 |
| Test level | Integration — creator check needs a PDP that returns per-type decisions |
| Gaps | G-SEC-24 |

When every check is allowed (and decidable), the task is created and the verdicts are kept in the task's authority record. The claim response carries them, so the worker knows exactly which resources it may act on downstream.

## Setup
- PDP: `{creator_a}` is allowed `share` on `gts.cf.docs._.document.v1~` `doc-77` with `owner_tenant_id eq {tenant_a}` (decidable).

## Exchange 1 — create
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json
Idempotency-Key: 91c3-share-doc-77

{ "type": "gts.cf.core.tasks.task.v1~acme.docs._.share.v1~",
  "queue": "gts.cf.core.tasks.queue.v1~cf.core.tasks.default.v1",
  "input": { "document_id": "doc-77" } }
```
- `201 Created`, `Location: /api/task_engine/v1/tasks/{task_1}`.

## Exchange 2 — claim
```http
POST /api/task_engine/v1/tasks/claim HTTP/1.1
Host: api.example.com
Authorization: Bearer <worker-a-token>
Content-Type: application/json

{ "worker_id": "reports-7f9c-1", "session_id": null, "queues": ["gts.cf.core.tasks.queue.v1~cf.core.tasks.default.v1"], "max_tasks": 1, "timeout_secs": 2 }
```
- `200`; the claim for `{task_1}` carries:
```json
{ "authority": { "mode": "creator_verified",
               "checked": [ { "source": "/document_id", "resource_type": "gts.cf.docs._.document.v1~", "action": "share", "verdict": "verified" } ],
               "checked_at": "2026-11-03T10:00:00Z" } }
```

## Side effects
- `metric te_creator_checks_total{outcome="verified"} increases by 1`.
- `task {task_1} state is claimed`.

## Notes
- `authority.checked` entries are `{ source, resource_type, action, verdict }`, verdicts as stored at creation (G-SEC-24; DESIGN.md:1043 names only "mode, checked sources, `checked_at`").
- A right revoked after creation is not re-checked (PRD.md:960); the claim still shows the creation-time verdict.
