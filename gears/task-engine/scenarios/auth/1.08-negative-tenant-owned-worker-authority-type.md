# A tenant-owned type declaring authority.mode = worker cannot be created

| | |
|---|---|
| Requirement | `cpt-cf-task-engine-fr-type-trust` (PRD.md:1012) · PRD.md:959, :1539 · DESIGN.md:1031, :1213, :2536 · ADR-0016:82, :98 |
| Phase | p1 |
| Test level | E2E — register type via types-registry, create refused |
| Gaps | G-CRT-15, G-SEC-21 |

`worker` mode means "the work uses only the worker's authority". Only platform-owned types may declare it; a tenant that registered such a type would turn shared workers into a confused deputy. The engine validates this when it first resolves the type and treats the type as non-creatable.

## Setup
- Tenant A registered `gts.cf.core.tasks.task.v1~acme.reports._.purge.v1~` (**purge**, tenant-owned) with trait `authority: { mode: "worker" }`.

## Request
```http
POST /api/task_engine/v1/tasks HTTP/1.1
Host: api.example.com
Authorization: Bearer <creator-a-token>
Content-Type: application/json
Idempotency-Key: 22ab-purge-1

{ "type": "gts.cf.core.tasks.task.v1~acme.reports._.purge.v1~", "queue": "gts.cf.core.tasks.queue.v1~acme.reports._.render.v1", "input": {} }
```

## Expected response
- `400 Bad Request`, category `invalid_argument`; one field violation on `/type` with reason `INVALID_TYPE_POLICY`; the `description` names the setting `authority.mode`.
```json
{
  "type": "gts://gts.cf.core.errors.err.v1~cf.core.err.invalid_argument.v1~",
  "title": "Invalid Argument",
  "status": 400,
  "detail": "Task type is not creatable",
  "instance": "/api/task_engine/v1/tasks",
  "trace_id": "<trace>",
  "context": {
    "resource_type": "gts.cf.core.tasks.task.v1~acme.reports._.purge.v1~",
    "field_violations": [ { "field": "/type", "description": "a tenant-owned type may not use authority mode 'worker'", "reason": "INVALID_TYPE_POLICY" } ]
  }
}
```

## Notes
- DESIGN.md:1213 names no reason code. Decided: every create of a type the engine finds non-creatable is `400` on `/type` with `INVALID_TYPE_POLICY` (G-CRT-15); the path is a JSON Pointer into the request (G-SEC-21). Every later create of **purge** gets the same answer until the type changes.
